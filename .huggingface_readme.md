# Market Intelligence AI Backend Service

AI-powered market intelligence backend service with real-time financial data integration and web search capabilities.

## Features

- 🔍 **Real-time Market Data**: Live stock prices, crypto data, company news
- 🤖 **Google Gemini AI**: Advanced AI with Google Search grounding
- 📡 **Streaming Support**: Server-Sent Events (SSE) for real-time responses
- 💾 **Context Memory**: SQLite-based conversation history
- 🔌 **MCP Integration**: Model Context Protocol for financial data

## API Endpoints

### Health Check
```bash
curl https://YOUR-USERNAME-market-intel-api.hf.space/health
```

### Query (Non-streaming)
```bash
curl -X POST https://YOUR-USERNAME-market-intel-api.hf.space/query \
  -H "Content-Type: application/json" \
  -d '{"message": "What is Bitcoin price?"}'
```

### Query (Streaming)
```bash
curl -X POST https://YOUR-USERNAME-market-intel-api.hf.space/query/stream \
  -H "Content-Type: application/json" \
  -d '{"message": "Latest Tesla stock news"}' \
  --no-buffer
```

## Environment Variables

The following secrets need to be configured in Space settings:

- `GEMINI_API_KEY`: Your Google Gemini API key (required)
- `FINANCIAL_DATASETS_API_KEY`: Financial data API key (optional)

## Tech Stack

- **Framework**: FastAPI + Uvicorn
- **AI**: Google Gemini 2.0 Flash with Search Grounding
- **Database**: SQLite
- **Protocol**: MCP (Model Context Protocol)
